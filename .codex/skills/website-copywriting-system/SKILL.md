# Website Copywriting System

Use this skill for website copy work in this project: creating, rewriting, adapting, reviewing,
or generating variants for page copy, landing-page sections, CTAs, SEO metadata, FAQs, and
desktop/mobile copy pairs.

Always balance:

- brand voice
- responsive desktop/mobile copy
- SEO intent
- conversion clarity

Do not treat these as separate unless the user explicitly asks for only one.

## Discovery

Before writing or reviewing copy, identify what is available:

- brand name
- product or service
- target audience
- page type
- page goal
- primary CTA
- primary SEO keyword
- secondary SEO keywords
- location or market
- tone of voice
- competitors or reference websites
- existing copy
- desktop/mobile layout constraints
- funnel stage

If information is missing, proceed with reasonable assumptions and list those assumptions briefly.
Do not block unless the missing detail would make the copy unsafe or misleading.

## Copy Principles

Prioritize clarity before cleverness. Use specific, natural, outcome-led language.

Prefer copy that is:

- specific
- active
- short
- natural
- benefit-led
- easy to understand quickly

Avoid vague marketing language, exaggerated claims, unsupported superlatives, and generic phrases
such as:

- revolutionary
- game-changing
- seamless solution
- unlock your potential
- take your business to the next level
- best-in-class
- cutting-edge
- world-class

Use those only if the user specifically asks for that style or provides proof.

Do not invent testimonials, statistics, awards, certifications, customer names, rankings, or proof
points. If proof is needed but unavailable, suggest the type of proof to add.

## Responsive Copy Rules

Desktop copy can be more descriptive. Mobile copy should be shorter and more scannable, but it must
preserve the core meaning.

Do not remove SEO-critical or conversion-critical information from mobile copy, including:

- product or service category
- target audience
- industry
- location modifier
- primary keyword
- main benefit
- main use case
- trust point
- CTA intent

Safe responsive rewrite:

- Desktop: `Accounting software built for growing Malaysian SMEs`
- Mobile: `Accounting software for Malaysian SMEs`

Risky responsive rewrite:

- Desktop: `Accounting software built for growing Malaysian SMEs`
- Mobile: `Work smarter`

Mobile length guidelines:

- hero headings: 4-9 words
- section headings: 3-8 words
- subheadings: 8-18 words
- CTAs: 2-5 words

Do not sacrifice clarity just to make copy shorter.

## Brand Voice

Infer the voice from:

- target audience
- industry
- price point
- product complexity
- trust level required
- page goal
- market expectations

Describe voice using:

- formality
- energy
- clarity
- emotion
- brand posture

Useful tone labels include: casual, semi-professional, professional, premium, calm, confident, bold,
playful, urgent, direct, explanatory, educational, persuasive, practical, aspirational, reassuring,
high-conviction, expert, partner, challenger, guide, and premium provider.

## SEO Rules

Match search intent first. Clearly state the page topic.

Use the primary keyword naturally in:

- H1
- intro paragraph
- body copy
- FAQ
- at least one H2 when appropriate

Use secondary and related terms naturally. Avoid keyword stuffing. Do not force exact-match keywords
if they make the copy sound unnatural.

Title tag guidance:

- include the primary keyword
- be specific
- include the brand name when appropriate
- usually stay under 60 characters when possible
- avoid clickbait

Good title structures:

- `[Primary Keyword] for [Audience] | [Brand]`
- `[Service] in [Location] | [Brand]`
- `[Product Category] Built for [Use Case] | [Brand]`

Meta description guidance:

- summarize page value
- include the primary keyword or close variant naturally
- include audience or use case when helpful
- include a soft CTA
- usually stay around 140-160 characters

Suggest internal links when useful, such as product pages, service pages, case studies, pricing pages,
contact pages, related blog posts, location pages, or industry pages.

## Landing Page Structure

Use a clear heading structure unless the user provides another structure.

A strong landing page usually includes:

- clear H1
- hero subheading
- CTA
- problem or pain section
- solution or product value section
- key benefits
- features or services
- how it works
- proof or trust section
- FAQ
- final CTA

The H1 must clearly describe the offer and should include the primary keyword or a close variant.
It should be human-readable, not overly clever, and not too generic.

Example:

- Strong: `HR Software for Payroll, Leave, and Attendance`
- Weak: `Work Better, Every Day`

FAQ sections should target real objections and search questions, including pricing, implementation,
compatibility, target users, service area, comparison, support, timeline, integrations, and security.

## Conversion Review Checklist

When reviewing copy, check:

- clarity
- relevance
- specificity
- differentiation
- benefit strength
- proof
- CTA quality
- friction
- page flow
- mobile clarity
- SEO safety

Ask whether the user can understand the offer in five seconds, what problem is being solved, why the
user should trust the brand, why the user should act now, what might stop the user from converting,
whether the CTA matches readiness, whether the copy is too feature-focused, whether proof points are
missing, and whether mobile copy preserves desktop meaning.

Flag issues such as:

- vague hero headlines
- weak CTAs
- missing audience clarity
- unsupported claims
- benefits hidden under features
- unclear differentiation
- mobile copy that removes important meaning
- SEO keywords disappearing on mobile
- too much text above the fold
- section headings that do not communicate value
- repeated claims
- missing objection handling
- missing trust signals
- missing final CTA

Scoring:

- 5: excellent
- 4: strong with minor improvements needed
- 3: usable but needs improvement
- 2: weak
- 1: major rewrite needed

## Final Check

Before finalizing, check that the copy is:

- clear
- specific
- brand-consistent
- SEO-safe
- mobile-friendly
- conversion-focused
- easy to implement
- free from unsupported claims

Be direct, practical, and ready-to-use. Use tables when comparing desktop and mobile copy. Explain
risks briefly. Avoid long theory unless asked.
